# Batch F: Web Appendices

This batch covers the additional web-only SLP3 appendices that extend the core book beyond `A-D`.

Included appendices:

- `E` Statistical Constituency Parsing
- `F` Context-Free Grammars
- `G` Combinatory Categorial Grammar
- `H` Logical Representations of Sentence Meaning
- `I` Word Senses and WordNet
- `J` PPMI
- `K` Frame-based Dialogue Systems

Batch goals:

- extend repo coverage to the extra Stanford web appendices
- keep appendix implementations NumPy-only and contract-bound
- expose deterministic fixtures and evaluation packs for symbolic and lexical appendices

Folders:

- `fixtures/` deterministic appendix inputs
- `eval_packs/` serialized evaluation bundles
- `notes/` appendix-family notes
